## ✈️ Flagship Project — ACDM (De-icing System)

🧊 **Airport Collaborative Decision Making – De-icing**

A **real-time scheduling and optimization system** used during winter airport operations.

✨ Highlights:

- ⚙️ Optimizes **aircraft-to-de-icing resource allocation**
- 🧩 **Dynamic rule engine** for runtime business rule configuration
- 🔴 **Live updates via SignalR** for planners and coordinators
- ⚡ Built for **low latency, data consistency, and concurrency**
- 💰 Reduced **fuel costs**, **take-off delays**, and improved airport efficiency

**Tech:** Angular · ASP.NET Core · SignalR · Azure · CI/CD
